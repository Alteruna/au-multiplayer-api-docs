      Remarks

      The delay from microphone to audio output on other clients consists of several parts.
      1. Microphone recording buffer.
      2. Lenght of the packet being sent. Default is 100ms (SendFrequency)
      3. Network latency / ping.
      4. Unity audio stream delay.
      5. Playback buffer. 200ms or less.

      Ways of improving delay are decreasing SendFrequency, changing unity playback buffer (DSP Buffer Size), and using an alternative solution for audio streaming.
