      [DocStyle(format=md, fields.title=Pages, fields.itemformat=s)] ![logo](https://user-images.githubusercontent.com/62545992/172627175-a494afbf-3600-460b-aea8-6cf988dcdc90.png)\n # Welcome to the Alteruna Multiplayer Migration Guide!\n ## Who is this for?\n This guide is for developers who already know [Photon PUN 2](https://www.photonengine.com/pun), [Photon Fusion](https://doc.photonengine.com/fusion/current/getting-started/fusion-intro), [Unity Netcode for GameObjects](https://docs-multiplayer.unity3d.com/), or [FishNet](https://fish-networking.gitbook.io/docs/), and want to know where their existing mental model does - and does not - carry over to **Alteruna Multiplayer's Unity SDK** (like every guide here, this is about the Unity package specifically, not Alteruna's server or other platform SDKs).\n It assumes you already understand networked identities, RPCs, and state replication in general; it does not re-teach those concepts from scratch. If you are new to multiplayer development altogether, start with the [User Guide](T_Alteruna_Guides_UserGuide.htm) instead.\n \n ## The short version\n Most of what you know transfers directly: identities, RPCs, and replicated fields all have a near-equivalent in Alteruna. The one idea worth unlearning is that a server exists by default. Photon (PUN 2 and Fusion) elects a Master Client or a host, Netcode and FishNet are built around a host or dedicated server process, but Alteruna is **peer-symmetric by default** - every peer runs identical code, and a dedicated server is an opt-in deployment choice rather than a starting assumption.\n That one difference is why Alteruna also ships a primitive ([resource locking](F_Alteruna_Guides_MigrationGuide_Part04OwnershipPossessionAndResourceLocking.htm)) that the other frameworks leave for you to hand-roll.\n \n ### Discord\n Join the [Alteruna Discord server](https://discord.gg/QT8KTe2Hzk) to find additional resources and other developers to chat with!\n \n ---\n [← Back](F_Alteruna_Guides_DeveloperGuide_Part03ForceSync.htm) | [Next →](F_Alteruna_Guides_MigrationGuide_Part01OverviewAndConceptMap.htm)\n
