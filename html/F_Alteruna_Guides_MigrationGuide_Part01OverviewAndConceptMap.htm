      A single table mapping the core concepts of Photon PUN 2, Photon Fusion, Unity Netcode, and FishNet onto their Alteruna Multiplayer Unity SDK equivalents.

      The concept map

      Same jobs, five vocabularies. The rest of this guide walks through each row.

      Concept Photon PUN 2 Photon Fusion Netcode for GameObjects FishNet Alteruna

      Remote calls [PunRPC] + photonView.RPC() [Rpc(...)] [ServerRpc] / [ClientRpc] [ServerRpc] / [ObserversRpc] [SynchronizableMethod] + BroadcastRemoteMethod() / InvokeRemoteMethod()

      Server tier one client is Master Client host, dedicated server, or peer-authoritative Shared Mode fixed host or dedicated process dedicated-first, host mode optional peer-symmetric by default, dedicated optional
      Per-object update rate observed-component serialization rate fixed simulation tick + interpolation global tick, hand-tuned per-SyncVar send rate Bucket LOD (5 tiers, Hz per tier)

      Worth calling out: Fusion's Shared Mode - where every client simulates and any client can hold state authority over an object - is the one topology among these that's actually close to Alteruna's peer-symmetric default. If you already have a Fusion Shared Mode project, the topology mindset in Part 05 should feel familiar rather than foreign.
