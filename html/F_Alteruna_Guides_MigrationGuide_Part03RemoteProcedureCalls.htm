      Remarks

      [DocStyle(reformatRemarks)] <h1>Remote procedure calls</h1> <p>Netcode and FishNet split RPCs by <em>direction</em> - a client can only call <span class="c">[ServerRpc]</span>, the server can only call <span class="c">[ClientRpc]</span>/<span class="c">[ObserversRpc]</span> - because both frameworks assume a real client/server split exists. Alteruna doesn't assume that, so <span class="c">[SynchronizableMethod]</span> has no direction baked in: it's one call shape, and you choose the <em>audience</em> instead. Fusion's newer unified <span class="c">[Rpc]</span> attribute (<span class="c">RpcSources</span>/<span class="c">RpcTargets</span>) is the closest thing to Alteruna's model here - it also replaced Photon's own older direction-based <span class="c">[PunRPC]</span> for the same reason.</p> <div class="alteruna-compare-tabs"> <button type="button" class="alteruna-compare-btn active" onclick="AlterunaShowComparisonTab(this,0)">Alteruna</button> <button type="button" class="alteruna-compare-btn" onclick="AlterunaShowComparisonTab(this,1)">Photon PUN 2</button> <button type="button" class="alteruna-compare-btn" onclick="AlterunaShowComparisonTab(this,2)">Photon Fusion</button> <button type="button" class="alteruna-compare-btn" onclick="AlterunaShowComparisonTab(this,3)">Netcode for GameObjects</button> <button type="button" class="alteruna-compare-btn" onclick="AlterunaShowComparisonTab(this,4)">FishNet</button> </div>
      C#
      [SynchronizableMethod]
void TakeDamage(int amount) => hp -= amount;
void Fire() => BroadcastRemoteMethod(nameof(TakeDamage), 10);

      [PunRPC]
void TakeDamage(int amount) => hp -= amount;
void Fire() => photonView.RPC(nameof(TakeDamage), RpcTarget.All, 10);

      [Rpc(RpcSources.All, RpcTargets.All)]
void TakeDamage(int amount) => hp -= amount;
void Fire() => TakeDamage(10);

      <p>Need a single target instead of everyone? Swap <span class="c">BroadcastRemoteMethod</span> (always includes the sender) for <span class="c">InvokeRemoteMethod</span>, which takes a <span class="c">UserId</span> or a <span class="c">List&lt;ushort&gt;</span> - the audience argument does the job Photon's <span class="c">RpcTarget</span> enum, Fusion's <span class="c">RpcTargets</span>, and Netcode's Server/Client split do separately.</p> <p>Watch the difference between the two "everyone" targets, since it's easy to get backwards:</p> <ul> <li><span class="c">UserId.All</span> (the default) sends to every <em>other</em> client and skips the sender - the equivalent of Photon's <span class="c">RpcTarget.Others</span>.</li> <li><span class="c">UserId.AllInclusive</span> sends to everyone, the sender included - the same audience as <span class="c">BroadcastRemoteMethod</span>, and the equivalent of Photon's <span class="c">RpcTarget.All</span>.</li> </ul>
      C#
      InvokeRemoteMethod(nameof(TakeDamage), UserId.All, 10);          // everyone except me
InvokeRemoteMethod(nameof(TakeDamage), UserId.AllInclusive, 10); // everyone, me included
