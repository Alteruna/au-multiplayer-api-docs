      UserGuidePart05PackageContent

      Gives an overview of the prefabs that Alteruna provides to easily get started with a project without programming.

      Prefabs

      Room Menu

      The RoomMenu prefab contains a menu shows a list of all the Rooms available to the registered license.
      To start and join a new Room, click the Start button. To join a Room, click the Join button next to it.

      Whenever you want to leave a Room, click the Leave button in the Room Menu.

      Text Chat

      The TextChat prefab has a chat box which can be used by users to chat amongst one another.
      Alternatively, can be used by developers to use cheats to make development faster by making sure
      that there are easily accessible shortcuts.
