      ServiceListener Class

      Base implementation of IServiceListener where every event does nothing. Derive from it and override only the events you need.

      Remarks

      Synchronizables registered with AddSynchronizable(ISynchronizableElement) are looked up by the service when their state arrives from other users.

      Example

      C#
      class Listener : ServiceListener
{
    public override void OnRoomJoined(Room room, User me) => Console.WriteLine("Joined " + room.DisplayName);
}
