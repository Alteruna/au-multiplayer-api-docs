      MultiplayerManager Properties

      Properties

      ApplicationData 
      AvailableRooms A list of all the currently available Rooms on the server.
      CurrentRoom The Room we are currently connected to.
      InRoom Whether currently connected to a Room.
      Instance Static singleton instance of the Multiplayer component. Note that this feature may not work as intended when used in combination with the multi-client tool.
      IsAuthenticated 
      IsConnected Whether currently connected to a server.
      IsConnecting Whether currently connecting to a server.
      Latency Connection latency. When no connection is established, last connection will be returned.
      LowestUserIndex The index of the user with the lowest index. Updates after the other joined and room joined events.
      MaxPlayers The global maximum amount of players allowed in a single Room. Rooms can be created with a lower player limit, but not higher.
      Me The User representing the local player.
      NetworkStatistics Statistic on network data send and received in Kilobytes unless defined.
      SimulateLatency Simulate latency by holding incoming packets for a random time. Only takes effect when the project's transport is set to TransportType.DefaultStatistics - the plain Default transport ignores this.
      SimulatePacketLoss Simulate packet loss by dropping random incoming packets. Only takes effect when the project's transport is set to TransportType.DefaultStatistics - the plain Default transport ignores this.
      SimulationMaxLatency Maximum simulated latency when SimulateLatency is enabled, in milliseconds.
      SimulationMinLatency Minimum simulated latency when SimulateLatency is enabled, in milliseconds.
      SimulationPacketLossChance Chance of packet loss when SimulatePacketLoss is enabled, in percent (0 - 100).
      Started True when the manager is ready to connect.
      State 
      TransportBytesReceived Total number of bytes received by the transport. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      TransportBytesSent Total number of bytes sent by the transport. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      TransportPacketLoss Total number of packets detected as lost. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      TransportPacketLossPercent Packet loss as a percentage (0 - 100) of packets sent. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      TransportPacketsReceived Total number of packets received by the transport. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      TransportPacketsSent Total number of packets sent by the transport. 0 unless the project's transport is set to TransportType.DefaultStatistics.
      UID 
      UIDString Get the unique identifier of the Alteruna Multiplayer instance as a string.
