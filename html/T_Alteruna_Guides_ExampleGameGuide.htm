      A hands-on, step-by-step walkthrough that puts the concepts from the User Guide into practice by building a small multiplayer game.




      Welcome to the Alteruna Multiplayer Example Game Guide!

      What is the Example Game Guide?

      While the User Guide introduces the concepts behind Alteruna Multiplayer, this guide shows them
      in action. You will build a small 2D multiplayer project from scratch: setting up the Multiplayer Component,
      creating a Player Avatar, spawning it when a User joins a Room, and testing it with multiple instances.
      If you haven't already, read through the User Guide first to get familiar with
      the core concepts used in this tutorial.
